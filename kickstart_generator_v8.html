01 프리셋 선택 여기서 고르고 아래를 세부 조정하세요▾

프로파일을 바꾸면 파티션·패키지·VM 설정이 통째로 전환됩니다. 프리셋을 적용하면 VM 디스크 용량도 자동 계산됩니다.

03 가상머신 (virt-install) CPU · RAM · qcow2 · 브리지▾

브리지 이름은 호스트마다 다릅니다 (br0, Bridge0, bond0 …). ip -o link show type bridge 로 확인하세요. --os-variant 는 호스트의 osinfo-db 에 등록된 값만 쓸 수 있습니다.

04 네트워크 고정 IP · DHCP · /etc/hosts▾

⚠ VM의 NIC 이름은 호스트와 다릅니다. 호스트가 eno1 이어도 게스트는 보통 enp1s0 입니다. 이름을 잘못 적으면 anaconda가 network 줄을 조용히 무시하고 DHCP로 떨어집니다. link 를 쓰면 이름과 무관하게 잡힙니다.

05 디스크 · LVM 볼륨그룹 · 파티션 · 논리볼륨▾

볼륨그룹(VG)
VG 이름소속 디스크
용량 단위 | swap 자동
유형마운트디스크/VG LV 이름FSMB grow

유형 — part: 물리 파티션(/boot 등, 디스크 지정) · efi: EFI 시스템 파티션 · lv: 논리볼륨(VG 지정). grow 체크 시 남은 공간을 모두 사용합니다.

07 설치 후 작업 (%post) 유틸 설치 · 서비스 · 튜닝▾

⚠ 설치가 끝나면 ISO 가 분리되고 RHEL 은 구독 등록 전까지 repo 가 하나도 없습니다. 이 설정이 없으면 %post 의 dnf install 이 전부 실패합니다. ISO → /iso 복사 를 쓰려면 아래 07번 카드의 "ISO 를 CD-ROM 으로 연결" 이 켜져 있어야 합니다.

08 OS 상세 설정 locale · hosts · sysctl · ssh · ftp · noexec (TNMS 가이드 기준)▾

Infinera 가이드에서 dnf install -y 로 하나씩 설치하도록 안내한 목록입니다.
⚠ jemalloc 은 RHEL 8 설치 ISO(BaseOS/AppStream)에 없고 EPEL 저장소에만 있습니다. 설치 미디어만으로는 조용히 빠지므로, 위 EPEL 옵션을 켜거나 rpm 을 따로 받아 설치해야 합니다.

09 WS-NOC 전용 설정 IPv6 비활성 · ip_forward · inotify · chrony · 브리지▾

브리지(Bridge0) 생성 파라미터 — 호스트 설치 시

호스트는 보통 킥스타트 없이 직접 설치하므로, 이 값들은 미리보기의 "브리지 생성 명령" 으로도 출력됩니다(호스트에서 복사해 실행). %post 에서 Bridge0 생성 을 켜면 킥스타트 안에도 포함됩니다.
